# 日志字号与视图尺度排期调整

本人日志列表、本人及下属日志详情的正文采用与下属摘要一致的15px和1.55行高；编辑输入和评论保留各自字号。

所有可见的已发布、未完成、非审核中任务都可从独立正常入口调整排期，不要求自己创建或负责。拖动**只在本人日程**可用：任务表单和下属日程不生成拖动、端点或画布调时入口；下属导航链只允许评论。独立正常详情按当前字段权限办理，仅排期权限与服务端可调时资格分开。

## 月历：按日显示、按天调整

月历按任务实际占用的**公司日期**绘制日级任务框，不按日内小时缩窄或偏移。09:00—12:00 与全天任务占同一个日期格；跨日任务连续覆盖占用日期，截止恰为次日 00:00 时不多占次日；零时长任务保留零工期，只在所属日显示时点标记。标题和显示的时刻/日期放在日级框内，窄屏裁切时由悬停提示和详情提供完整内容。

本人月历整条平移按公司日期差量改变起止，保留原日内时刻和工期；拖动真实开始/截止端点按天调整对应日期，保留该端时刻并改变另一端。跨周/月续接段不冒充真实端点，但可整体平移完整任务，差量按抓取日与目标日计算。触屏在月历上先判方向：纵向滑动手势继续滚动月历，横向超过阈值才进入拖动。

## 日视图：仅完整普通日内区间可按小时调整

横向/纵向日轴按一小时相对差量调整并保留原分钟，例如 09:20 向后一步为 10:20。整条平移保持工期，端点调整保持另一端不变；当日零时长任务的真实两端可分别命中。只有完整起止区间落在当前公司业务日 `[00:00, 次日00:00)` 的普通定时/零时长任务获得整条、端点和方向键入口；午夜截止可作为当日真实终点且不生成次日副本。

历史全天任务、纵向**全天区**、完整覆盖当天的定时任务以及跨日任务在当日呈现的首段/尾段/中间截取片段，都不提供整条平移、端点或键盘调时。它们仍可在全天区或时间轴各显示一次、普通点击进入详情，并从独立正常详情精确调整排期；整日覆盖优先排除，即使完整区间恰好一天。全天区不再提供小时拖动，也不再重复进入时间轴。

## 轻量确认、失败与待审投影

松手后打开独立的轻量排期确认，只展示原排期、新排期（全天任务只显示完整日期）、原因和提交，不进入完整任务表单；月历按天、日轴按小时共用这一弹层。打开弹层和提交前都会回读任务版本、冻结、完成、权限和期限状态；提交沿用已有幂等写入，响应丢失后重试复用同一请求标识，服务端只保存一条申请。取消、Esc、pointercancel、失去指针捕获、无位移或逆序都不写入，也不会误开详情或日期清单；失败保留原因和草稿，旧差量不会自动套到新版本。

审核按本次操作者的直属上级，固定创始人沿用免审规则。审核中须先处理原申请，已完成须先重开。普通详情和提醒始终使用有效版本。

已发布任务在修改、进展、完成、重开和交接等审核期间使用虚线外框、淡底和“审核中”，保留共用首标签颜色。申请包含新排期时，本人和有权下属日程只在**提议位置**显示一个虚线框，月历按日级跨度、日轴按实际时段，标题时刻与框内位置同源；实际生效排期、提醒、详情和表单继续使用有效版本。通过后按新排期显示实线，驳回/撤回/失效恢复原有效排期；刷新或重新登录仍保持唯一位置。待审期间不能再次拖动。

## HTTP 写入兼容

HTTP 测试地址已兼容浏览器随机标识接口差异；遇到旧的 `crypto.randomUUID` 报错页面，请强制刷新后重新打开排期并提交。相同请求重试复用标识，避免重复创建审核申请。

## 验证入口

```sh
CHROME_BIN=… python3 backend/scripts/check_schedule_drag.py
CHROME_BIN=… python3 backend/scripts/check_subordinate_workspace.py
CHROME_BIN=… python3 backend/scripts/check_calendar_drawer.py
python3 backend/scripts/check_visible_schedule_permissions.py
CHROME_BIN=… python3 backend/scripts/check_request_id_compat.py
```

`check_schedule_drag.py` 覆盖月历日级几何（三小时/全天同宽、午夜不占次日）、按天整条与端点、跨年、日轴小时与分钟、全天/整日覆盖/跨日首尾/中段无拖动及键盘调时、无位移不误开详情、失去捕获取消、全天确认只显示日期、轻量确认响应丢失重试只建一条申请，以及待审虚线位置/标题时刻/首标签颜色和通过/拒绝/撤销/失效后的恢复。`check_calendar_drawer.py` 继续覆盖月/日几何、全天区、连续月份与抽屉，`check_visible_schedule_permissions.py` 覆盖仅排期资格。所有脚本使用一次性随机测试库，退出自动清理。
