# 日志字号与小时排期调整

本人日志列表、本人及下属日志详情的正文采用与下属摘要一致的15px和1.55行高；编辑输入和评论保留各自字号。

所有可见的已发布、未完成、非审核中任务都可调整排期，不要求自己创建或负责。拖动月历或横向日视图的任务框可整体平移，拖动框的左右边缘可修改起止；纵向日视图使用上下方向。每次按一小时调整，原分钟保持。例如09:20向后一步变10:20。边缘也支持聚焦后用方向键调整。

日程不再显示“调时、起、止”按钮，文字放在实际任务框内。月历按日格宽度/24换算小时，例如09:00—12:00从当天宽度的9/24处开始，只占3/24。跨日任务首尾按实际时刻显示，中间完整覆盖的日期才占全天。短任务文字裁切，悬停提示和详情提供完整名称与时间；点击极短任务的边缘但不拖动，仍可查看任务。本人及下属月/日视图使用相同的框体和边缘操作。

松开后进入仅排期确认，填写原因再提交；审核按实际操作者的直属上级，创始人沿用免审规则。提交前取消、Esc、手势取消、逆序或旧版本不能保存。排期权限不放开资料、标签或负责人编辑。审核中须先处理原申请，已完成须先重开。任务详情的“调整排期”可精确填写日期与时刻。

已发布任务在修改、进展、完成、重开和交接等审核期间使用虚线和淡底，保留标签颜色。申请提交成功后，框的位置、长度、框内时间和标题一起使用新申请排期，原位置不保留重复条；重新读取后仍保持。实际生效排期与提醒继续使用已审核版本。通过后恢复实线并采用新排期，驳回/撤回/失效则恢复原有效排期。待审期间不能再次拖动。

HTTP测试地址已兼容浏览器随机标识接口差异；遇到旧的crypto.randomUUID报错页面，请强制刷新后重新打开排期并提交。相同请求重试复用标识，避免重复创建审核申请。
