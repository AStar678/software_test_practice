# 日志字号与视图尺度排期调整

本人日志列表、本人及下属日志详情的正文采用与下属摘要一致的15px和1.55行高；编辑输入和评论保留各自字号。

所有可见的已发布、未完成、非审核中任务都可调整排期，不要求自己创建或负责。拖动**只在本人日程**可用：任务表单和下属日程不生成拖动、端点或画布调时入口，但可以进入普通任务详情并按当前用户原有权限操作（基础资料仍只属于业务责任方，仅排期权限独立）。

## 月历：按日显示、按天调整

月历按任务实际占用的**公司日期**绘制日级任务框，不按日内小时缩窄或偏移。09:00—12:00 与全天任务占同一个日期格；跨日任务连续覆盖占用日期，截止恰为次日 00:00 时不多占次日；零时长任务保留零工期，只在所属日显示时点标记。标题和显示的时刻/日期放在日级框内，窄屏裁切时由悬停提示和详情提供完整内容。

本人月历整条平移按公司日期差量改变起止，保留原日内时刻和工期；拖动真实开始/截止端点按天调整对应日期，保留该端时刻并改变另一端。跨周/月续接段不冒充真实端点，但可整体平移完整任务，差量按抓取日与目标日计算。触屏在月历上先判方向：纵向滑动手势继续滚动月历，横向超过阈值才进入拖动。

## 日视图：按小时调整

横向/纵向日轴按一小时相对差量调整并保留原分钟，例如 09:20 向后一步为 10:20。整条平移保持工期，端点调整保持另一端不变。纵向**全天区**的历史全天任务与完整覆盖当天的定时任务同样提供整条平移、真实端点和方向键入口，仍只在全天区展示一次、不在时间轴重复。

全天区示例：

- 历史全天任务 `2030-12-31 00:00 — 18:00`：拖开始端点一小时得到 `01:00 — 18:00`，拖整条得到 `01:00 — 19:00`。
- 定时整日任务 `00:00 — 次日 00:00`：拖截止端点一小时得到 `次日 01:00`，开始不变。

焦点落在透明边缘后可用方向键按小时调整；这些都进入原仅排期确认与审核流程，不改写其他字段。

## 确认、审核与待审投影

松开后进入仅排期确认，显示完整起止日期时刻，填写原因再提交；审核按本次操作者的直属上级，固定创始人沿用免审规则。提交前取消、Esc、手势取消、逆序或旧版本不能保存。审核中须先处理原申请，已完成须先重开。任务详情的“调整排期”可精确填写日期与时刻。

已发布任务在修改、进展、完成、重开和交接等审核期间使用虚线外框、淡底和“审核中”，保留标签颜色。申请包含新排期时，本人和有权下属日程只在**提议位置**显示一个虚线框，月历按日级跨度、日轴按实际时段，框内文字与位置同源；实际生效排期、提醒、详情和表单继续使用有效版本。通过后按新排期显示实线，驳回/撤回/失效恢复原有效排期；刷新或重新登录仍保持唯一位置。待审期间不能再次拖动。

## HTTP 写入兼容

HTTP 测试地址已兼容浏览器随机标识接口差异；遇到旧的 `crypto.randomUUID` 报错页面，请强制刷新后重新打开排期并提交。相同请求重试复用标识，避免重复创建审核申请。
