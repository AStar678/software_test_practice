## 修复内容

| 问题 | 修复后的行为 |
| --- | --- |
| 评论通知绕过当前任务权限 | 失权或评论删除后清除通知的任务、对象与审核跳转；历史任务接口返回 404。普通任务通知保留原有历史只读行为。 |
| 撤回评论通知恢复已删除或失权正文 | 上级查看撤回通知的例外也检查评论是否仍存在且可读；普通任务通知的既有例外保持。 |
