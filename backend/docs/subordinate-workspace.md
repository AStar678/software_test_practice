# 下属资料与工作查看

我的 → 下属资料按真实直属关系逐层排列。左侧加减按钮展开或收起，点击姓名进入所选人员专用工作页；创始人和管理者能看到授权的下属及其下属，普通员工显示暂无下属。

工作页为独立全屏小屏设计，顶部姓名、职位和组织，下方日程/日志切换。日程参考本人日历提供月视图和日视图，默认月历，按公司日期查看当前负责的授权任务。月历按周一至周日排列，显示跨日连续任务条；超过容量时点+N进入完整当天。日视图提供00:00至24:00时间轴、重叠任务分栏、全天区和任务清单切换。箭头在月历按月翻页、日视图按天翻页；日期选择可跳转，今天回当前日。跨日延续、整日、午夜截止、零时长和完成状态保持真实。点任务进入详情，返回仍是该人员、该日期和月/日模式。

日志按日期卡片展示摘要，点击全文进入详情及评论，每页十条、可加载更早日志。本人日志页仍只显示本人，个人日历和任务表单范围不变。人员详情返回会重新校验权限并读取内容；没有权限、加载失败会清空工作列表并提示重试。

资料按当前返回权限显示手机号和合法交接预设入口，不因进入下属工作页扩大业务操作权。界面没有代替下属编辑日志或拖动日程的入口。

本地验证：`CHROME_BIN=… python3 backend/scripts/check_subordinate_workspace.py`。随机测试库自动创建清理，截图和报告位于output/subordinate-workspace/。需要先构建backend/target/pandora-backend-0.1.0.jar。本轮不做手机真机测试，仅真实浏览器尺寸模拟；云端发布另行处理。
