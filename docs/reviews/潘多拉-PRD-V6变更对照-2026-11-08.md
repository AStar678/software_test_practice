## 二、主要旧规则替换

| V5 旧口径 | V6 处理 |
| --- | --- |
| 首页四板块独立滚动，含最近日志 | 改为事件纪、任务看板、每日事项三模块；移除首页最近日志；上方卡片不内部滚动 |
| 每日事项横向浏览、单日期、仅数量标记 | 改为纵向连续月历、日级跨天条、起止日、名称和完整命中日清单 |
| 表单置顶不影响任务表格排序 | 改为表单置顶独立于月视图置顶，完整结果分组后排序分页 |
| 月/日拖动无需长按，日视图未限制调整后当天边界 | 改为手机长按约半秒启动、轻震反馈；日视图调整前后均须留在当天 |
| 日志按创建时间影响前端排序 | 改为按所属日期倒序；前端不得重新按创建时间排序 |
| 邮箱仅本人可见 | 改为本人及实际管理链上级在授权下属资料弹窗可读 |
| 下属工作区普通任务详情按原权限显示操作 | 改为下属导航链仅评论；独立本人正常入口仍按原字段权限 |
| 通知三个下拉筛选 | 改为顶部类型标签、已读分段和单图标精简/完整切换 |
| 演示以旧四身份和 110 条分页事项为主 | 改为动画公司四角色、每人 10—20 条有意义任务，极端分页只做测试数据 |

## 三、保留边界

- 固定组织、真实账号和稳定内部 ID 不变。
- 审核仍按申请人当前直属上级；固定创始人免审；非创始人无有效上级阻断。
- 任务表单仍仅本人原始创建或当前负责并集；月视图仍仅本人有效负责。
- 标签仍由创始人维护；任务多选、日志单选/不选。
- 通知先过滤再计数分页、打开即读、全局未读数独立。
- 历史通知只读、撤回、失权裁剪和评论独立鉴权继续有效。
- `android/` 原生工程本轮排除；旧套壳震动和长按必须在 `android-shell/` 真机核验。
