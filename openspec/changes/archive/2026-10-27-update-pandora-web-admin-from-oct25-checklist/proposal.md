## Why

2026-10-25《潘多拉 Web 与管理端代码修改清单》的 25 项要求需要形成可实施、可独立验证的统一变更。新 PRD 尚未发布，本次以用户指定的修改清单及本轮范围确认作为需求依据；清单中的 V3 章节号仅用于追溯，不将 V3 PRD 作为本次验收基线。

## What Changes

- 调整员工 Web 日历：仅本人有效负责的正常任务、月/日两模式、纵向完整日时间轴、密集任务全量展示、侧栏及悬浮创建、跨月连续滚动；接通已有任务表单并调整手机列序。
- **BREAKING** 员工改用手机号登录；创建任务候选扩展到本公司全部有效员工；创建及创建申请重提改由创建人的直属上级审核，创始人或确实无直属上级者创建免审。候选扩展不扩大查看权、交接权或非创建操作权限。
- 移除创建及创建重提的完成标准字段和必填校验，允许创建人不负责；补齐真实审核提示、重开改期、失效创建重提与仅审核人可见的有序字段差异。非创建审核保留现有未被清单替换的业务规则。
- **BREAKING** 日志统一命名，增加部门→团队→个人逐层搜索；允许补写公司今天、昨天、前天，编辑和删除统一于真实创建后 24 小时冻结，并堵住删除重建绕过。
- 新增任务/日志共用单选标签及平铺评论：创始人在“我的”维护标签，统一配色并保留删除引用；评论作者可管理本人评论，新评论仅通知有效任务负责人或日志作者且排除本人。
- 正式 PC 管理端增加任务历史查询和通知管理；员工 Web 提供获授权部门负责人的受限团队创建/转交入口；准备持久化、可连续展示的演示数据。
- 时间选择器使用 Web 自有时分控件，覆盖创建、编辑、重开；保留移动浏览器适配，Android WebView 容器适配和设备验收由套壳接手人另行负责。
- 按用户本轮范围调整，将旧安卓 Web 套壳的资源同步、导航/桥接/容器适配、APK 构建签名、覆盖升级及设备验证整体移出本 change，交由具备环境的其他人员另行负责；保留交接事项，不作为本 change 完成或归档的前置条件，也不视为已交付。

无新 capability 目录。新增标签、评论和演示数据要求归入项目现有业务 capability，避免重复规格。

### Modified Capabilities

- `pandora-requirements-aligned-prototype`：替换本次冲突的业务基线、日历、创建派发/审核、员工登录、日志日期及冻结要求，补充任务表单、审核交互、管理端及团队入口，新增共用标签、评论和演示数据，明确 Android 套壳交付不属于本 change 的验收范围。

- 需求来源：`docs/reviews/潘多拉-Web与管理端代码修改清单-2026-10-25.md`；其中已确认保留行为继续有效，未覆盖功能保留现状及不冲突的已确认规则。不编造或等待新 PRD，也不自动修订历史 PRD。

- 配套后端：Spring Boot 认证、组织授权、任务审核、工作区、通知/outbox、演示种子，MySQL/Flyway 数据迁移及相关 Java、HTTP 和浏览器检查；沿用真实认证、ETag 和幂等写入机制。
