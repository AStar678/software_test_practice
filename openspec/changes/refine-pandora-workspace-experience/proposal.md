# Proposal

## Why

潘多拉的首页、日程、员工日志与通知承担日常浏览和处理，但月历手势不统一，补写日志时也需要手动查找相关工作。演示库已有真实权限和四级组织结构，业务内容仍难呈现同一家公司从目标到执行的过程。

## What Changes

- 首页每日事项改用与公司月历一致的纵向月视图样式，继续使用独立的每日事项数据。事件纪和任务看板支持卡片内滚动与展开的二级详情弹窗，展示完整正文和可用时间信息。
- 公司日历和首页每日事项从接口获取年度节假日数据，随国务院公告自动同步节日名称、放假和调休上班标记。公司任务表单按本人独立置顶排序。
- 写日志时自动关联所属日的全部本人事项和符合条件的跨日任务。每日事项正文仍仅对作者可见。日志预览使用所属日期。
- 本人日程支持长按抓取任务并跨屏拖动，边缘自动滚动，设备支持时提供震动反馈。
- 首页增加入职天数。员工资料用部门、团队和职位面包屑呈现职务，显示授权手机号、入职日期和入职天数。员工日志和员工日程均可连续纵向浏览月份。
- 通知首页提供常用快捷筛选和更多筛选，保留组合查询、分类和详情流程。
- 使用同一组相互关联的真实业务场景串联创始人、部门负责人、团队负责人和员工的演示数据。

## Impact

涉及员工 Web 首页与工作区、公司日历和表单、员工资料与入职日期维护、后端日志关联和查询、通知筛选以及演示库。震动验收以支持 Web Vibration API 的移动浏览器为准，其他浏览器提供可见的抓取反馈。
