# Design

## Context

当前版本ed9a331已上线。日志列表实际正文是未带log-content类的p，原主题字号选择器没有匹配；下属摘要为15px。月历/横向轴只有22px端点，纵向轴无拖动入口；已有CDP测试只覆盖前两种视图和特定手柄。

## Goals / Non-Goals

**Goals:** 真实阅读字号一致，三种排期显示均可用小时调整，框内信息清楚且边缘拖动支持鼠标/触摸/键盘。

**Non-Goals:** 不扩大任务资料编辑权、自动跳过原因审核、修改后端审核生效机制或数据库结构、进行真机测试或默认发布云端。

## Decisions

- 明确给日志正文阅读类，使用共享15px阅读变量，匹配真实列表/详情结构，评论与编辑输入不受影响。
- 一步恒为1小时相对增量，保留原分钟。月历条按实际24小时比例绘制，拖动按日格宽度/24换算每小时，小屏可从详情精确调时；横向日轴60px一小时，纵向日轴60px一小时并用纵向位移。移除可见起止按钮，使用透明边缘命中区与方向键；零时长两端分离。
- Pointer捕获的异常、取消、离屏释放与失去捕获均恢复预览；抑制拖动后的普通点击，防止误开月格清单/任务详情。键盘按对应方向每次一小时。滚动起始在手柄之外保留原行为。
- 提案仍通过P.openScheduleChange复用编辑、原因与ETag校验；所有可见未完成非待审任务都有排期专用入口，普通编辑权限保持；冻结/完成任务不可调。

- 已发布任务响应携带最小pendingSchedule（起止时间及全天日期），仍保留原有效字段。只在日程投影使用申请排期，不覆盖TASKS和详情的实际有效版本；所有待审已发布日程使用虚线、淡底及审核中标识。下属范围查询显式选择待审日程投影，跨日跨月查询不得漏项，仍按原任务/人员授权筛选；不会暴露提案正文或新负责人。
- 审核通过/驳回/撤回/失效后刷新移除待审样式，位置由新有效版本或原有效版本决定；未发布创建申请不进入日程。

- 后端新增reschedule命令，仅允许起止/全天日期及原因；仍存为change审核，提交和生效时都校验可见性，非业务责任方仅能有排期差异。资料/负责人/标签/进展不获额外编辑权。预览用reschedule按实际操作者上级路由。
- 月历每段保存真实起止比例，由真实时段层绘制，文字位于真实时段框内，过窄时裁切并保留完整提示和详情，命中区不虚增时段；可拖动任务条整体平移或拖动起止，跨周续接段可平移完整任务，详情保留精确排期入口。下属月历同样显示小时占比并支持授权框体/边缘拖动。

- 公共P.mutation优先使用可用的原生randomUUID，否则用getRandomValues生成RFC4122 v4格式标识，不依赖弱随机源；标识仍缓存在原重试槽中，同一请求重试不换键。用映射到127.0.0.1的非localhost测试域模拟普通HTTP不安全上下文，复现用户报错并测试提交已到达服务端但响应丢失的重试。

- 月/横向日/纵向日/下属视图的文字置于实际时段层内；任务框自身移动，透明边缘区调整端点，不再渲染“调时、起、止”按钮。待审框只按pendingSchedule绘制，正常详情仍为有效排期。小段文字裁切，完整任务名称和日期由无障碍名称、悬停提示及详情提供，不为文字扩大真实时长。

## Risks / Trade-offs

- [月格小时比例太窄] → 展示真实时段条、文字在框内裁切，拖动按日格宽度/24换算每小时，端点和精确调时入口保留可点击大小。
- [父级点击/滚动吞手势] → 手柄独立命中、touch-action:none及点击抑制，真实鼠标/触摸/键盘和纵向轴回归。
- [小任务端点相互遮挡] → 起止分开定位和放大命中区，验证点任务及短任务。

## Migration Plan

无迁移。隔离库与真实浏览器验证后更新本地预览；云端发布另行处理。
