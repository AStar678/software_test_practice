## Solver/Product Fixes This Session

- `createTask(date)` ran before the task-integration module's asynchronous create preparation finished, so `drafts.task` was still empty and the requested business date was silently dropped (an empty-day "按该日期创建" opened the default dates). It now applies the date after the returned promise resolves, via the normal form rebuild.
- Month-grid click suppression kept the pointer origin after `pointerup`, so any later pointer move (even without a button pressed) re-armed the suppression and could swallow the next real click. `origin` is now cleared on pointer end and ignored when no button is pressed.
- The all-day block used a grid with a percentage `max-height` and a non-scrolling child, so a sixth task was clipped instead of scrollable. It is now a flex row whose list scrolls (`min-height:0`, `overflow-y:auto`), verified with 20 all-day tasks.
- The calendar's month task bars had no deterministic keyboard activation (headless Chrome dropped a synthetic Enter on the focused button). The shipped keydown handler now opens the selected covered day for `Enter`/`Space`, and `ArrowLeft/Right/Home/End` move the selection across a bar; native click activation is checked separately.
- Closed-layer `inert` attributes are re-synchronized on every redraw and on account reset, so a stale `inert` cannot lock the calendar after a sheet closes.
