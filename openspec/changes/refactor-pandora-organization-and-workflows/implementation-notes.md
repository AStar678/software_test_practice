## Solver/Product Fixes This Session

- `WorkspaceService.canReadTask` no longer calls the transactional `TaskService.approval` probe inside the event-delivery transaction. The old path could mark the worker transaction rollback-only on a legitimate 404 and abort all notification delivery with `UnexpectedRollbackException`. `TaskService.canReadRequest` now performs a plain read-only visibility check. `check_review_routing.py` proves worker delivery, reviewer-only submission copies, result matrices and reminders.
- Task read endpoints (`list`, `detail`, `adminTasks`, `approvals`, `approval`, `reviewerPreview`, handover preset/targets, `taskHistory`, assignee candidates) call `Access.requireCurrent`, so an actor captured before an organization version change cannot keep an old role/scope.
- Dedicated handover preview in `潘多拉-任务接入.js` now sends `operation:"handover"`. Without it the preview validated the change rule and told the current owner "申请人已不具备该操作权限"; the handover form then had no targets. Browser chain covers the fixed path.
- Log page now has a real "补写" entry that opens the first missing day among today/yesterday/the day before, allowing backfill after today's log exists; it reports when all three days are already written.
