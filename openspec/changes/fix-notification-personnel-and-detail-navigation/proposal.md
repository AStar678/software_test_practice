# Proposal

## Why

通知中的临期、逾期分类及原申请入口不一致，人员缓存和下属详情返回路径会给用户造成错误信息或丢失浏览位置。此变更按用户确认先处理八项缺陷与界面清理，原四个变更继续待独立验证和归档。

## What Changes

- 将真实临期、逾期事件统一归入提醒，列表筛选与详情一致。
- 核查结果通知绑定的原申请及访问权：有权者查看原申请，无权者保留合法结果摘要并移除无效入口，不新增提议或比较权限。
- 更新人员缓存，准确展示组织身份、职位、真实部门。
- 下属日程中的任务详情返回原人员、模式和日期；个人日历外的任务隐藏置顶入口。
- 人员资料移除公司行；日志详情移除编辑权限行，保留编辑操作及冻结状态。
- 清理员工产品界面的开发解释与冗长规则说明，保留必要校验、状态、结果及简短统计来源。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `pandora-requirements-aligned-prototype`: 补充通知分类与申请入口、人员展示及详情导航和精简文案的验收约束；不改变现有审核及对象访问规则。

## Impact

员工 Web 主界面、共享套壳页面资源、WorkspaceService 通知投影与现有申请权限探测。无数据库结构变更。使用隔离数据库和桌面浏览器验证，不连接手机，不自动上线。
