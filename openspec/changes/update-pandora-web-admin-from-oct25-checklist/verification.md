- Category: implementation
- Severity: high

- Evidence: `backend/src/main/java/cn/pandora/auth/AuthService.java:64` uses `Db.find`; `common/Db.java:30` returns the first row even when multiple match. `V19__employee_phone_login.sql:32` deliberately leaves the unique index absent when old phone data has duplicates, but populated conflicting keys are retained and no login-side ambiguity check exists.
