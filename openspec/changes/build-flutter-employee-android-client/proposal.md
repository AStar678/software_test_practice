## Why

员工客户端需要从 Web/套壳迁移到可继续跨平台发展的 Flutter，同时完整保留现有协作业务并落实 2026-11-08 的新交互。早期 Java 工程未经验证；以真实后端和当前 Web 的最终有效行为为基线新建 Flutter 工程，更适合完成这次整体迁移。

这是完整迁移的 B，依据[迁移盘点](../../../docs/reviews/潘多拉-Flutter完整迁移盘点与Change边界-2026-11-08.md)的全部 90 项、54 条主规格及 J01–J32，而非只实施 12 项新指导。用户已要求现在先提出 B；共享契约 change [A](../prepare-employee-client-contracts-and-business-upgrade/proposal.md) 尚未实施，实施顺序仍为 A → B。

## What Changes

- 新建真正使用 Flutter 控件的完整员工客户端，覆盖创始人、部门负责人、团队负责人、普通员工；保留“首页、公司、日志、统计、我的”及所有二级流程，不把业务界面包装成 WebView。
- 完整迁移认证/强制改密、会话与账号隔离、任务创建/有序负责人/父子关系/字段编辑/进展/完成/重开、申请审核/diff/撤销/失效、专用交接与预设；服务端仍裁决权限、版本和幂等。
- 完整迁移本人月/日历、全局个人任务表单及两种独立置顶、日志全生命周期、共用多标签与创始人维护、平铺评论、本人资料/头像、真实下属只读工作区、站内通知全生命周期及真实统计/本地规则建议。
- 落实新指导：纵向连续范围事项月历与实际命中日清单；首页少量预览且先清单后详情；独立表单置顶；官方节假日标识；按日志所属日主动追加名称；约 500ms 长按/单次轻震、月历二维跨月拖动、日轴最终日边界；真实入职时长、组织职务路径及授权下属邮箱；日志所属日排序；连续人员日程；六类×三已读状态通知布局；真实四角色动画演示。
- 使用 A 最终输出的范围事项、`/tasks/table`、`/table-pin`、日志填充、资料投影及节假日接口；其余现有服务复用。B 实施前必须核对 A 的独立验证、归档后规格和交接契约，发现变化先修订 B 规划，不按当前提案猜测接口已经可用。
- 新 Flutter Android 包采用独立 applicationId，与 `cn.pandora.mobile.debug` 旧套壳共存；提供可复现 APK 构建、签名说明、真实后端联调及安卓设备证据。会话安全存储、系统返回、前后台/进程重建、选图、键盘、安全区、字体放大和网络失败属于交付范围。
- 修订主规格里仅适用于过渡 Web 的载体/旧交互约束；新客户端以 Flutter 交互为准，业务授权和数据语义继续共用。员工 Web 保持参考/过渡，独立管理员继续 PC，不在本 change 停用旧入口。

系统推送按用户决定继续延期，完整站内通知在范围内；不新增移动管理员、全公司通讯录、私人标签、周视图、日志月历、离线写入或外部 LLM。本轮仅创建规划，不修改工程代码、数据、APK或主规格。

## Capabilities

### New Capabilities

- `flutter-employee-client`：完整员工业务在 Flutter 的交互、契约接入、上下文权限、会话/恢复、跨模块状态、Android 共存安装与真实交付证据。

### Modified Capabilities

- `pandora-requirements-aligned-prototype`：将五页载体、首页预览、事项连续月历与状态展示、资料职务路径、下属连续日程、通知布局、触摸拖动及交付范围明确为 Flutter 最终行为，同时保留 A 定义的 Web 过渡边界。涉及 A 的条目以 A 的预期归档结果为前置版本，顺序应用，不并行覆盖。

## Impact

- 新工程拟位于 `flutter/`，包含 Dart 业务/数据/界面分层、Android 宿主、资产、测试和构建说明；旧 `android/`、`android-shell/` 不作为实现基础，不替换其包或迁移其本地登录态。
- 接口继续使用现有 `/api/v1` 和 A 的增量，无独立移动后端、重复审批引擎或数据库迁移。A 的最终交接文档 `backend/docs/employee-client-contracts.md` 是实施输入，当前尚未生成。
- 依赖包括 Flutter/Dart、状态/路由/HTTP、安全存储、时区和图片处理；具体选型及锁定方式见 design。领域日期与权限模型不依赖 Android，实现可为未来平台复用；首轮只交付安卓。
- 验证覆盖全部迁移项和 32 条路径，按 Flutter 逻辑/组件、真实 API 集成和安卓设备分层取证；服务或旧 Web 的 PASS 不能替代 Flutter 交付。PC 管理操作及 A 迁移作为跨端联动依赖验证，不迁入员工客户端。
